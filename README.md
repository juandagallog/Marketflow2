# Papel y Luna

Sistema POS web para una papelería desarrollado con HTML, CSS y JavaScript vanilla.

## MVP - Primera entrega

El sistema incluye:

- Creación y cierre de ventas.
- CRUD de productos.
- Historial de ventas.
- Persistencia mediante LocalStorage.
- Navegación entre módulos.

## Estructura

- `pos.js`: flujo de ventas.
- `productos.js`: CRUD.
- `historial.js`: historial y facturas.
- `storage.js`: persistencia.
- `app.js`: inicialización y navegación.
